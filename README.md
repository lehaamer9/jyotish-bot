# 🔮 ИИ-Джьотиш Астролог (Telegram Bot)

Telegram-бот ведической астрологии (Джьотиш), сочетающий высокоточные астрономические вычисления по эфемеридам NASA JPL с глубокой текстовой интерпретацией через нейросеть **Google Gemini**.

---

## 🌟 Возможности бота

- 🧮 **Натальная карта (Кундли D1):**
  - Точный расчёт асцендента (Лагна) и домов (бхав).
  - Позиции всех 9 ведических грах (Сурья, Чандра, Мангала, Будха, Гуру, Шукра, Шани, Раху, Кету).
  - Сидерический зодиак, истинная аянамша Читра Пакша (Лахири).
  - Накшатры, пады, градусы, ретроградность и достоинства планет (экзальтация / дебилитация).
  - Полная Панчанга (Титхи, Накшатра, Йога, Карана, Ваара).
  - Сила планет по Шадбале (в рупах).

- ⏳ **Периоды жизни (Вимшоттари Даша):**
  - Баланс даши при рождении.
  - Полный календарь Маха-Даш и Антар-Даш на всю жизнь.
  - Автоматическое определение текущего активного периода.
  - Трактовка текущих энергий и рекомендаций от ИИ.

- 💞 **Совместимость парных карт (Кута / Аштакута):**
  - Сопоставление двух натальных карт.
  - Анализ по 8 ведическим показателям гармонии (Варна, Васья, Тара, Йони, Граха Майтри, Гана, Бхакут, Нади).
  - Персональные выводы и советы для отношений.

- 🤖 **Синтез через Google Gemini:**
  - Никаких выдуманных планетных координат — расчёты производятся строго математическим ядром, а ИИ выступает как интерпретатор классических текстов (Парашара, BPHS, Джатака Париджата).

## 🚀 Быстрый старт

### 1. Подготовка ключей

1. **Telegram Bot Token:**
   - Напиши боту [@BotFather](https://t.me/BotFather) в Telegram.
   - Отправь `/newbot`, задай имя и username бота.
   - Скопируй полученный токен (вида `123456789:ABCdef...`).

2. **Google Gemini API Key:**
   - Перейди на [Google AI Studio](https://aistudio.google.com/apikey).
   - Нажми **"Create API key"**.
   - Скопируй бесплатный ключ.

### 2. Настройка проекта

Создай файл `.env` в папке бота (на основе `.env.example`):

```bash
# В PowerShell в папке jyotish-bot:
Copy-Item .env.example .env
```

Открой `.env` в блокноте или редакторе и вставь свои ключи:

```env
TELEGRAM_BOT_TOKEN=123456789:AA...твой_токен
GEMINI_API_KEY=AIzaSy...твой_ключ_gemini
```

### 3. Установка зависимостей (если ещё не установлены)

```powershell
pip install -r requirements.txt
```

### 4. Запуск бота

```powershell
python bot.py
```

После появления надписи:
```
🚀 Джьотиш-бот успешно запущен и ожидает сообщений...
```
открой своего бота в Telegram и нажми `/start`!

## 📱 Команды в боте

| Команда | Описание |
|---------|----------|
| `/start` | Приветствие и быстрый старт |
| `/chart` (или `/natal`) | Пошаговый ввод даты, времени и города для расчёта натальной карты |
| `/dasha` | Полная раскладка периодов Вимшоттари Даша и анализ текущего периода |
| `/compat` | Анализ совместимости двух карт (запрашивает данные партнёра) |
| `/mydata` | Просмотр сохранённых данных твоей натальной карты |
| `/reset` | Сброс сохранённых данных и ввод заново |
| `/help` | Подробная справка |
| `/cancel` | Отмена текущего шага в диалоге |

## 💡 Лимиты и стоимость

- **NASA JPL эфемериды**: Полностью бесплатные и локальные (скачиваются один раз при первом запуске).
- **Google Gemini 2.0 Flash**: Бесплатный tier даёт до **1500 запросов в день** (15 запросов в минуту), чего более чем достаточно для старта проекта с аудиторией в сотни пользователей.
